# Client N.A. — Client Portfolio Review

Course submission for **IE MBA — Asset Management & Capital Markets** (Prof. Andrea G. Angelone):
a portfolio review and investment recommendation for an anonymised client, "Client N.A.",
valued at 4 November 2026.

## How to open

- **Online:** open the GitHub Pages URL of this repository. The landing page is `index.html`.
- **Locally:** run `python -m http.server` in this folder and open <http://localhost:8000/>.


All links are relative, so the site works from a GitHub Pages sub-path (`https://<user>.github.io/<repo>/`).
Pages carry `noindex,nofollow` and `robots.txt` disallows crawling.

## Files

| Path | What it is |
|---|---|
| `index.html` | Landing page: executive summary, key figures, downloads, methodology and AI-use note |
| `deliverables/report.pdf` | Report (PDF) |
| `deliverables/report.docx` | Report (Word) |
| `deliverables/model.xlsx` | Excel model |
| `deliverables/README.md` | Expected deliverable filenames |
| `robots.txt` | Disallows all crawlers |
| `.nojekyll` | Serves files as-is on GitHub Pages |

External resources: Google Fonts (EB Garamond, Hanken Grotesk) and Plotly 2.35.2 from cdnjs, with jsDelivr and unpkg as fallbacks.
Without network access the pages still load with system fonts; charts that need Plotly show a notice.

Educational exercise. Not regulated investment advice.
